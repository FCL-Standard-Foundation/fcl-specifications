## Branch and release identity

- **`main` (or current default branch)** — current development tip. Contents may change without constituting a new published version identity.
- **Tags / releases** — identify **published snapshots** of specifications. Cite tagged versions (and each document’s own version field) when referring to a published draft or release.

Released specification versions are immutable; normative corrections require a new version. See [CONTRIBUTING.md](../CONTRIBUTING.md).
